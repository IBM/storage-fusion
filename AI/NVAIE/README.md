# NVIDIA AI Enterprise (NVAIE) SBOMs

[NVIDIA AI Enterprise](https://www.nvidia.com/en-us/data-center/products/ai-enterprise/) NIM
container images are distributed as part of IBM Storage Fusion under the NVAIE commercial
agreement between NVIDIA and IBM.

## SBOMs

A Software Bill of Materials (SBOM) is a machine-readable inventory of every software component
inside a container image — packages, libraries, and binaries — with exact versions and
identifiers. It enables CVE correlation without pulling or running the image.

Each file is a **[CycloneDX 1.4](https://github.com/CycloneDX/specification/tree/1.4)** JSON document generated by the Anchore SBOM Generator. One SBOM
per NIM container image. Contents:

| Field | Description |
|---|---|
| `metadata.component` | Container image name and digest |
| `metadata.properties` | Image labels: NIM type, model ID, NSPECT scan IDs, base OS |
| `components[]` | All OS, Python, and binary packages installed in the image |

Each component entry carries a `purl` (Package URL) for CVE correlation. The SBOM is bound to an
immutable `sha256` image digest; `serialNumber` and `NSPECT-*` labels provide audit linkback to
NVIDIA's security scan records.

See [`SBOMS/fusion-2.14/README.md`](SBOMS/fusion-2.14/README.md) for per-image details.
