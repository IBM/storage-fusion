## Maximo Backup and Restore with IBM Fusion

Backup and restore of Maximo with Fusion utilizes recipes to orchestrate the backup and restore flows. 

- For Maximo MAS 9.0, use the Fusion backup and restore with recipes flows for the respective Fusion version [2.8](2.8.x/README.md), [2.9](2.9.x/README.md), [2.10](2.10.x/README.md), [2.11](2.10.x/README.md).

- For Maximo MAS 9.1, use the [Fusion dynamic recipes flows for backup and restore](9.1.x/README.md), which is supported with Fusion 2.12 and later.
